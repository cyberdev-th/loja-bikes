# Loja de Bicicletas

Sistema de gerenciamento de loja de bicicletas, com CRUD de produtos, interface no console e persistência em MySQL.

## Funcionalidades

- Cadastro de produtos (nome, preço, categoria, estoque)
- Listagem, busca, atualização e remoção
- Persistência em banco MySQL
- Interface de linha de comando (CLI)
